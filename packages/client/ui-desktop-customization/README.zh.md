# Desktop 个性化

[English](README.md) | 中文

面向学员桌面版的浏览器插件，提供视觉增强、应用内背景选择、软件版本信息和“赋范空间出品”品牌入口。只有 Desktop Host 设置 `DSH_DESKTOP=1` 时才挂载；持久化和当前版本读取通过固定的 Electron preload bridge 完成。更新卡片分别标注 Studio 外壳版本和内嵌 Harness 核心版本。

本包提供“官方原版”“大肥鱼拟人”“云端猫咪”“九天·深空算力穹顶”“九天·量子玻璃实验室”和“九天·晨曦算力网络”六套具名皮肤。“官方原版”不加载背景图片或皮肤配色层；“大肥鱼拟人”仍是桌面端首次启动与恢复默认时使用的皮肤；其余五套作为可切换选项。持久化时只记录稳定标识，不会把内置图片重复写入 `userData`。自定义背景仍接受不超过 16 MB 的 PNG、JPEG 或 WebP，在本机生成 1920×1080 WebP，保存到 Electron `userData`，并通过 ThemeRuntime 应用配色变量。用户选择的图片不会上传。

视觉增强设置行与对话输入区快捷按钮读取同一份 Host 状态。唯一开关根据确切模型元数据只选择一条路线：具备图片能力的主模型接收原生请求，文本模型才使用已经验证的兼容旁路。配置弹窗可选择阿里云百炼或 OpenRouter；百炼固定使用 `qwen3.8-max`，OpenRouter 则允许用户输入兼容的视觉模型，默认使用 `openai/gpt-4.1-mini`。用户填写的 Key 保存到应用自有的凭证引用；环境中的 `DASHSCOPE_API_KEY` 与 `OPENROUTER_API_KEY` 只作为只读后备来源，绝不会成为写入目标。内置 DeepSeek 视觉模型通常通过可复用的 Files API 引用接收确定性请求图片；文件解析失败时，整次请求回退为有界内联图片。两条原生分支都不会调用兼容旁路。关闭时，快捷按钮会直接启用原生路线，或在确需兼容设置时进入同一个真实图片验证流程；开启时，它通过同一设置命名空间关闭能力；悬浮卡片说明当前选择的路线。Host 推送设置或凭证变化后，两个入口会同步刷新。

## 模型体验

无。这个浏览器侧包只负责控制 Host 拥有的视觉能力，本身不注册模型可见上下文。

#### KV Cache 影响

本包自身不增加 token 或 KV Cache 条目；通过此界面开启视觉增强后，Skill、Tool 与视觉观察的影响均由 Host 侧能力负责。

## 已知限制与暂缓事项

- 软件更新页当前分别显示已安装的 Studio 与 Harness 版本；在线检查、下载和安装入口统一禁用，并引导学员前往发布页。
- 签名安装包、三端发布元数据和发布动作留到三端封装阶段完成。
