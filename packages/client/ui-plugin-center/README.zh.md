# Desktop 插件中心 UI

[English](README.md) | 中文

仅 Desktop 启用的“插件中心”和“插件发现”一级入口：`sidebar.primary.action` 提供两个导航动作，`main.page` 提供各自的独立页面。插件中心用于搜索已验证目录、在普通插件与 Bundle 封装 Skill Pack 之间切换、在同一页面打开确定版本详情并理解缓存新鲜度。插件发现将公开插件目录呈现为紧凑的编辑式视图，包括搜索、依据已审核元数据形成的能力分类、服务端拥有的精选、热门与最近更新顺序、右侧确定版本详情面板，以及相同的受信任安装确认。“让 Agent 找插件”允许用户直接描述使用场景，由当前 Agent 调用内置 `find-plugins` Skill 从公开 `dsh-plugin` 目录筛选推荐；未配置 DeepSeek 时先打开现有模型设置，推荐返回对话，安装仍进入插件中心的兼容检查与确认流程。安装兼容预检展示当前 Desktop、DSH、Node、平台与 Profile 事实、有序拒绝原因、重启预期、能力和广泛权限风险。如果确定版本已经安装，插件发现会直接说明它是已启用还是未启用，并引导进入“管理”，不再执行重复安装预检。已安装管理器连接系统、目录和本地来源，以及启用、运行、更新与待处理事实；插件发现将已安装条目送回该管理器，而不重复生命周期控制。目录归属条目提供经确认的启用、停用、确定更新和卸载旅程；卸载默认保留配置和插件自有数据，只在提交后单独提供有界数据删除确认。不兼容的已审核 Bundle 继续可见，并解释不能激活的原因。

Windows Desktop 会在目录标题栏为原生窗口按钮预留安全区域，使目录新鲜度信息与刷新操作避开最小化、最大化及关闭按钮。

Preset 广场是与插件中心、插件发现平级的第三个一级页面。“广场”视图负责公开搜索、下载量/最新排序、详情和经校验的 `.dshpreset` 安装；“已安装”视图负责 Host 实时本地名单、系统项保护、用户项删除，以及使用所选 Preset 创建空白会话。两个视图在变更过程中都留在当前页面，远端目录失败也不会隐藏本地 Preset。浏览器开发只提供确定性的只读 fixture，并明确提示安装、删除与会话选择必须在 Desktop 中执行。

目录会在社区条目之前以独立的 **赋范官方** 分组展示随应用交付的六套工作流。卡片与详情明确说明这是赋范团队维护的内容，不代表 DeepSeek Harness 官方。安装后仍为普通用户 Preset，因此可从“已安装”删除，也可在目录里重新安装。

浏览器开发固定使用 `pnpm run dev:desktop:web`（`dev:plugin-center` 保留为兼容别名）。该入口以 `DSH_DESKTOP=1` 组合与 Desktop 相同的客户端 UI 名册和皮肤，同时把 `DSH_HOME` 隔离在项目工件目录；插件中心在页面根节点留下开发模式标记与悬停说明。默认场景把安装和已安装动作回放为一个会话持久操作与累计已安装投影，并覆盖卸载后的自有数据确认；`pluginCenterScenario=compatibility-denied` 还会展示一个因应用升级不兼容而保持停用的 Bundle。`pluginCenterScenario=stale` 拒绝陈旧目录权威，`pluginCenterRecovery=failed` 提供不写文件的恢复失败、诊断导出与重试旅程。该入口只用于 UI 与状态旅程验收：其已安装结果、变更、数据删除和诊断导出都是模拟状态，不提供真实 MCP 进程、Electron preload、文件系统、包管理器或 Host 重启权威。

渲染器接收固定目录方法、操作状态方法，以及只接受 `operationId` 的恢复重试和诊断导出意图。只有用户确认确定版本并明确接受应用级广泛权限后，页面才会发送安装意图。意图只包含插件 id、确定版本与幂等键，绝不接受包名、registry、URL、路径、证据、环境、策略、命令或原始 Skill 来源。生产环境会暴露操作形状，但在 F005 剩余恢复矩阵和包体验收完成前保持 `mutationsEnabled` 为 false。

## 模型体验

只有用户主动提交“让 Agent 找插件”需求时才调用当前 Agent。页面把经过长度限制的原始需求作为 `/find-plugins` 参数发送；按需加载的内置 Skill 使用只读脚本搜索公开 npm 目录，并要求模型只根据返回结果给出最多五项推荐。插件元数据始终视为不可信内容，Agent 不会自动安装或改变插件状态。缺少 DeepSeek 配置时不会发送请求，而是打开现有模型设置。

#### KV Cache 影响

普通目录浏览无影响。Agent 查找会新增一个用户回合并按需加载稳定的 Skill 指令；用户需求和实时目录结果是动态内容，不承诺跨请求缓存命中。

## 已知限制与暂缓事项

- **F001 使用内置已审核 fixture**：生产目录服务、发布、排行与下架流程由 F006 持有。
- **插件发现不虚构增长指标**：页面保留当前服务端拥有的精选、热门与最近更新顺序，并且只渲染从已审核摘要元数据推导出的分类；增长视图需要未来目录字段提供可审计的增长证据。
- **Agent 查找只覆盖可安装公开目录**：内置 Skill 只推荐带 `dsh-plugin` 标签、声明确定 Bundle patch 与不可变分发证据的 npm 包，不把任意 GitHub 仓库或通用 Skill 冒充为当前可安装插件。
- **真实生命周期变更继续受发布闸门限制**：已安装管理和恢复源码路径已经存在，但 F005 剩余恢复矩阵及 macOS/Windows 包体验收通过后，生产环境才能启用动作。
- **浏览器开发桥接没有系统权限**：真实 Profile、MCP、Electron IPC、文件系统、包管理器与 Host 重启行为需要 Desktop 验收。
