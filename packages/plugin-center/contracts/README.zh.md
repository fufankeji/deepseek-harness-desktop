# 插件中心合同

[English](README.md) | 中文

供 Desktop 主进程与插件中心客户端共享的严格 JSON 兼容目录、预检与可信安装操作合同。Skill Pack 只表示为带 `catalogKind: skill-pack` 和 `skill` 能力的已校验确定版本 DSH Bundle；本包不接受渲染器提供的包来源、Git URL、本地路径、可执行文件、环境或版本范围。

一份有界目录结果可以携带闭合的 `notice`，用于区分 GitHub 到 npm 映射成功、仓库只发布了部分包、仅有源码、未发现 DSH Bundle，以及网络失败后的缓存回退。该提示只解释发现上下文，绝不授予制品或变更权威。

Preset 广场使用独立的闭合合同，不扩展插件目录类型。其列表、详情、归档元数据、预览和安装解码器把公开条目与下载 URL 限定在 `https://www.dshdesktop.com/preset/`，拒绝未知字段，并且只把一个有界目标 id 带入本地导入操作。

每个解码后的条目还携带闭合的目录来源：`fufan-official` 或 `community`。来源只控制展示和内置归档解析，绝不会把安装后的用户 Preset 提升为受保护的系统信任。

目录解码器会拒绝未知字段，并在快照替换可信缓存前验证 id、确定版本、边界、允许的媒体来源、分区引用、时间戳、兼容摘要、激活证据，以及每个确定详情对应的一份可信预检。预检中的包与制品权威只保留在 Desktop 投影内，列表和详情读取绝不返回这些字段。

兼容性合同把三类权限源分开：

- 渲染器只提交 `pluginId`、一个确定 `version` 和一个闭集 `action`；
- 已校验目录提供包身份、语义版本范围、平台制品、摘要、能力、风险、冲突和预期运行态证据；
- Desktop 提供发布版本、平台、目录新鲜度、Profile 修订、已安装投影、受保护身份和当前操作状态。

每个决定只对这些确定输入有效，并携带稳定且有序的原因码。制品结果只暴露有界身份与原因事实，不包含压缩包字节或本地路径。强制的 `broad-application-authority` 披露可防止把技术校验后的元数据表述为官方代码审计或沙箱保证。

安装意图只包含插件 id、确定版本和稳定幂等键。已安装投影把包、Bundle、来源、保护、运行、更新、待处理动作、配置入口和声明自有数据保持为独立事实。启用、停用、更新和卸载请求复用确定身份与幂等形式；卸载后的数据移除还必须提供已提交操作 id、声明相对路径的有界子集，以及固定 `remove-owned-data` 确认。不可变操作快照使用一套有序阶段词汇和一套封闭失败词汇；启动结果区分新操作、同键加入和另一个活动操作，且不暴露包管理器权威。

## 模型体验

无；本包只验证目录与预检值，不注册任何模型可见内容；后续被激活的插件自行负责其模型可见行为。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- 本包只验证值，不负责获取目录、下载压缩包、变更 Profile、重启 Host 或证明运行态激活；这些副作用由 Desktop 拥有。
- V1 变更平台只包括打包的 macOS arm64 与 Windows x64，制品仅允许来自包括公开 npm registry 在内的已批准 HTTPS origin。
- registry 完整性、摘要、包身份与风险标签只能降低供应链不确定性，不构成 DeepSeek 安全审计，也不能隔离插件代码；已安装 Host 插件仍拥有广泛应用权限。
